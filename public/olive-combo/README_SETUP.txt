🌿 প্রিমি ফার্ম — ১ কেজি জলপাই আচার কম্বো ল্যান্ডিং পেজ (cPanel Setup Guide)
================================================================================

এই ফোল্ডারে থাকা ফাইলগুলো আপনার cPanel সাবডোমেইনে আপলোড করে খুব সহজেই লাইভ করতে পারবেন।

📂 ফাইলের তালিকা:
1. index.html   -> মূল ল্যান্ডিং পেজ (মোবাইল-ফার্স্ট, ফাস্ট লোডিং, হাই কনভার্টিং)
2. order.php    -> cPanel এর জন্য অর্ডার সেভিং স্ক্রিপ্ট (orders.csv তে অটো সেভ হবে)
3. .htaccess    -> হাই-ট্রাফিক অপ্টিমাইজেশন (Gzip ক্যাশিং ও ফাস্ট লোডিং)
4. images/      -> ৩টি হাই-রেজুলেশন রিয়েল প্রোডাক্ট ছবি এবং লোগো

--------------------------------------------------------------------------------
🚀 কিভাবে cPanel এ আপলোড করবেন (Step-by-Step):
--------------------------------------------------------------------------------
১. আপনার cPanel এ লগইন করে "File Manager"-এ যান।
২. আপনার কাঙ্ক্ষিত Subdomain এর ফোল্ডারে প্রবেশ করুন (যেমন: offer.premefarm.com বা public_html/olive-combo)।
৩. এই ফোল্ডারের ফাইলগুলো (অথবা ডেসকটপে দেওয়া .zip ফাইলটি) সরাসরি Upload করুন।
৪. জিপ ফাইল আপলোড করলে রাইট ক্লিক করে "Extract" করে নিন।
৫. ব্যস! আপনার সাবডোমেন ভিজিট করলেই ল্যান্ডিং পেজটি লাইভ দেখতে পাবেন।

--------------------------------------------------------------------------------
🔗 কিভাবে Bizmation (বিজমেশন) এ কানেক্ট করবেন:
--------------------------------------------------------------------------------
বিজমেশনে অর্ডার সরাসরি রিসিভ করার জন্য ২টি সহজ পদ্ধতি আছে:

পদ্ধতি ১: Bizmation Webhook / API URL (সর্বোচ্চ রেকমেন্ডেড)
১. আপনার Bizmation অ্যাকাউন্টে লগইন করে Settings > Webhooks / Integrations এ যান।
২. একটি New Order Webhook URL তৈরি বা কপি করুন।
৩. index.html ফাইলটি এডিট করে উপরের দিকে থাকা PREME_CONFIG অংশে লিংকটি পেস্ট করুন:
   BIZMATION_WEBHOOK_URL: "আপনার_বিজমেশন_ওয়েবহুক_লিংক"
৪. ফাইলটি সেভ করলেই কাস্টমার ফর্ম পূরণ করার সাথে সাথে অর্ডারটি সরাসরি বিজমেশনে পৌঁছে যাবে!

পদ্ধতি ২: Bizmation Custom Landing Page URL Linking
১. Bizmation ড্যাশবোর্ডে "Landing Pages" বা "External Store" অপশনে যান।
২. আপনার সাবডোমেন লিংকটি (যেমন: https://offer.premefarm.com) যুক্ত করুন।
৩. এই ফর্মে থাকা ফিল্ডের নামগুলো (customer_name, customer_phone, customer_address, delivery_area, quantity, total_amount) বিজমেশনের স্ট্যান্ডার্ড ফিল্ডের সাথে ১০০% মিল রেখে তৈরি করা আছে, তাই বিজমেশন স্বয়ংক্রিয়ভাবে সব ডাটা ক্যাচ করতে পারবে।

--------------------------------------------------------------------------------
🎯 Facebook Pixel / Meta Ads ট্র্যাকিং সেটআপ:
--------------------------------------------------------------------------------
১. index.html এর শুরুতে PREME_CONFIG অংশে আপনার পিক্সেল আইডি দিন:
   FB_PIXEL_ID: "আপনার_ফেসবুক_পিক্সেল_আইডি"
২. এতে স্বয়ংক্রিয়ভাবে:
   - পেজ ভিজিটে: PageView & ViewContent
   - অর্ডারে ক্লিক করলে: InitiateCheckout
   - অর্ডার সাবমিট হলে: Purchase ইভেন্ট (৳৭৯০ বা ৳১৫০০ সহ) ট্র্যাক হবে।

--------------------------------------------------------------------------------
⚡ হাই ট্রাফিক (High Ad Traffic) হ্যান্ডলিং সুবিধা:
--------------------------------------------------------------------------------
- শতভাগ স্ট্যাটিক ও লাইটওয়েট কোডিং—প্রতি ঘণ্টায় লাখ লাখ ফেসবুক অ্যাড ভিজিটর আসলেও সাইট স্লো হবে না বা ডাউন হবে না।
- ইন্টারনেট ড্রপ করলেও কাস্টমারের ডাটা ব্রাউজারের LocalStorage এবং cPanel এর orders.csv ফাইলে স্বয়ংক্রিয়ভাবে সুরক্ষিত থাকবে।
- ফুটারের "স্টোর ম্যানেজার লগইন" এ ক্লিক করে (পাসওয়ার্ড: preme2026) যেকোনো সময় লাইভ অর্ডার দেখতে ও Excel CSV ডাউনলোড করতে পারবেন।
